# 第一阶段关键逻辑说明

## 状态与身份

生命周期是 `draft → published → closed`，截止时间到达时无需后台定时任务也会拒绝填写；数据库 status 可仍为 published，公开接口的 `accepting=false` 表示有效关闭。已发布问卷不可编辑、不可再次发布、不可重新打开。草稿没有公开填写入口。`GET /api/surveys` 始终限定 owner_id，其他作者访问管理、统计和回答记录均返回404。

注册用户名3–40字符，允许中文、字母、数字、下划线和连字符，大小写敏感。密码8–128字符，随机16字节盐，PBKDF2-HMAC-SHA256 260000轮；使用常量时间比较。登录发放随机32字节会话 token，服务端只存散列，Cookie 为 HttpOnly / SameSite=Strict，HTTPS 下自动 Secure，默认24小时过期。退出立即删除该会话记录。所有填写接口也要求登录。

## 条件规则语义

规则保存在每道题的 `rules` 数组里，程序不按题号写死业务分支。

| 题型 | 操作符 | value 示例 | 命中条件 |
|---|---|---|---|
| single | eq | `"从不使用"` | 回答等于指定合法选项 |
| multiple | contains | `"开放时间"` | 回答数组包含该选项 |
| multiple | contains_all | `["插座","座位数量"]` | 回答同时包含全部指定选项 |
| number | eq/gt/gte/lt/lte | `7` | 对应数值比较 |
| number | between | `[18,30]` | 闭区间，18和30均命中 |

第一阶段不支持文本条件跳转，不执行用户表达式，不使用 eval。规则从上至下匹配，**首条命中生效**，之后规则不再执行；没有命中就进入下一题。目标只能是后续题目 ID 或 `END`。只允许前进，使控制流天然为 DAG，最多访问 N 道题，防止循环和重复答题。体检会拒绝回跳，不是运行后才截断循环。

多选同时命中不同规则时不合并目标，仍取第一条。可视化规则值中的多值以 `|` 分隔，如数字区间 `18|30`、包含全部 `插座|座位数量`。API 传值则是正常 JSON 数组。若选项本身含 `|`，在界面中不宜用于“包含全部”的组合值，可改用 API 完整 JSON 提交；单选或 contains 不受此分隔约定影响。

## 路径重算

```text
从第1题开始
  若为下一题预览且尚未提供当前题答案 → 返回当前题
  校验当前题答案
  记录当前题到 path，有效非空答案放入 answers
  依次匹配该题规则
    END → 结束
    后续题号 → 跳转
    未命中 → 下一题
结束后拒绝 path 之外的答案
```

预览 `/next` 与最终提交共用 `walk` 和 `validate_answer`。最终提交必须提供到达路径上所有必答题的合法答案。被跳过的必答题无需填写；若客户端伪造这些题的答案，返回422而不保存。未知题号也拒绝。选答题不答可用 null，空字符串/空数组归为未答，不保存该答案且不会触发规则。

`path` 保存访问题目（含空选答题），`answers` 只保存有效回答，`trace` 只保存真正命中的规则。前端返回上一题会清除该题及其后路径的数据，需要重新填写；这样改变前置选项时，旧分支不会混入新分支。

## 输入校验

| 类型 | 约束 | 反例与处理 |
|---|---|---|
| 单选 | 一个合法选项字符串 | 传数组、不存在选项 → 422 |
| 多选 | 合法且不重复的字符串数组，min_choices/max_choices | 重复选项、选择过少/过多 → 422 |
| 文本 | 字符串，min_length/max_length，硬上限10000字符 | 必答仅空白、过短、过长 → 422 |
| 数字 | 有限 JSON 数字，integer/min_value/max_value | 布尔、数字字符串、NaN、无穷、超界、小数代替整数 → 422 |

字符长度使用 Python `len`，按 Unicode 码点计数，不是字节数；组合表情可能由多个码点构成。必答文本只用 strip 判断是否全空白，存储时保留用户原始文本。手机号可按要求使用整数题，但前导0和超长编号不适合当数值，本系统不额外实现手机号专用题型。

数值、数值规则比较值及最小/最大约束的绝对值限定为9007199254740991，避免跨浏览器、Python与BSON存储时出现整数精度或溢出问题。

## 发布前自动体检

检查至少一道题、ID唯一、选择题选项至少2个/不重复/非空、区间上下界、题型与约束适配、选择数不超选项数、必答多选可回答、整数范围存在整数、规则操作符和值匹配、目标存在、目标只向前、截止时间在未来。错误阻止发布，警告不阻止发布。

多条规则会提示优先级与重叠风险；完全重复条件另给警告。当前未实现完整的符号可达性证明、所有可能答案组合枚举或自动识别所有重叠区间，因此“体检通过”表示这些结构和约束检查通过，不代表所有业务问题都已自动证明正确。作者应按验收样例运行关键分支。

## 并发与重试

每次客户端开始填写生成 request_id，点击提交或失败重试沿用该值。服务端以 survey_id + respondent_key + request_id 唯一索引实现请求幂等：已保存的同一请求返回同一回答ID和 `replayed=true`，即使此后关闭也可重放保存结果。相同 request_id 被视作同一次操作，不能用来修改已提交答案。

若不允许重复填写，额外保存 single_key，partial unique 索引在数据库层阻止同账号并发产生多份记录。若允许多次填写，每次新的 request_id 会保存独立回答。页面禁用提交按钮减少误触，真正的数据保证来自数据库唯一约束。

## 统计口径

只统计已成功插入的 responses，不统计未提交草稿、错误请求或准入计数。单选统计每选项次数和作答数；多选每个选项独立计数，次数之和可以大于回答人数。填空内容分页展示，可不断加载，数字平均值/最值基于全部该题回答，不只当前分页。没有数字回答时均值为 null，界面显示“—”。跳过和空选答题不进入回答人数分母。
